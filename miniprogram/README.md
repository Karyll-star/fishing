# 荒岛钓鱼小游戏

这是可操作的小游戏原型，包含手机浏览器试玩版与微信小程序原生页面源码。

## 立刻试玩

打开 `web/index.html` 即可开始游玩。进度保存在当前浏览器本地。

## 微信小程序

使用微信开发者工具导入 `miniprogram` 文件夹，选择小程序项目即可预览。当前 `appid` 使用游客预览占位值；发布前替换为你们自己的小程序 AppID。无需后端即可体验单机主循环。

## 操作与流程

1. 点“抛竿”，等浮漂下沉；也可提前点“等鱼咬钩”进入咬钩状态。
2. 提竿后反复收线，拉力过高时点“松线卸力”。
3. 鱼上岸后快速点三次收进鱼篓，及时收网可赚手快小费。
4. 到交易页卖鱼攒金币，或把鱼交给岛民换木料、绳索。用金币和材料升级鱼竿。
5. 准备好装备后挑战 Boss，逐岛前进，最终回应救援信号。

## 广告与付费原型

漂流补给箱模拟激励视频，商店模拟装饰与去广告权益入口。原型不会播放真实广告或发起支付。接入微信广告、支付前，需要替换成对应平台 SDK、配置广告位与合法商品，并补充服务端发奖/订单校验。

## 玩法参考

《How to Fish》的官方商店介绍概括了“钓鱼、处理鱼获、卖鱼、购买装备、完成任务和 Boss 挑战解锁新岛屿”的循环。本原型吸收该类成长节奏，同时使用独立的故事、角色、界面和操作细节，适配荒岛求生题材与触屏游玩。
