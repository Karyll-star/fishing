# 潮汐归途 · 改造说明

上游：[dgreenheck/tidewater](https://github.com/dgreenheck/tidewater)，基于提交 `4811ba48d795197de5621985f404e765c0b7c0ef`。

## 两个可玩入口

- **3D 海岛**：保留上游 WebGPU/WGSL 引擎、海浪、昼夜、船只、鱼竿、NPC、18 种鱼和真实张力遛鱼。汉化操作、引导、装备、图鉴、交易、设置和加载画面。
- **轻量触屏版**：Canvas 2D 绘制；与 3D 版共享 `GameState`、`FishTable`、`Gear`、`CatchMinigame`、`Expedition` 和商业化适配器。用于手机浏览器与微信原生小游戏。它不包含上游的 WebGPU 海面渲染。

## 主线

海难 → 漂木湾（3 份材料）→ 雾岬集市（4 份材料）→ 风暴礁（6 份材料）→ 归航。

任意鱼都能向岛民换取木材、绳索、金属，或出售为贝币。修船后挑战本岛首领。首领使用上游的收线/泄力机制；失败免费重试，修船材料不再扣除。胜利赠送下一段旅程的鱼线升级，降低免费路线的重复刷取需求。

3D 岛屿使用不同地形噪声种子及天气、时间组合，保留相同的中央港湾与建筑布局；并非三个独立美术制作的大地图。

## 商业化演示

- 漂流箱：主动观看演示后领取木材和绳索。
- 鱼饵包：特殊鱼饵加快咬钩，普通鱼饵无限。
- 装备试用：5 分钟鱼线/收线加成。
- 鱼获加奖：最近一次鱼获等值贝币，每条只能一次。
- 救回鱼获：仅普通鱼，不能用广告跳过首领。
- 每日最多 3 次激励奖励，按北京时间刷新。广告提前关闭、失败不发奖。
- 虚构品牌“潮途”的外观与便捷包提供不扣款的内购演示。演示商品每个存档只能体验领取一次。

正式微信广告需要广告位 ID。真实支付需服务端签名、订单查询、支付通知校验、按订单号幂等发货及服务器背包同步。详见 [WECHAT.md](WECHAT.md)。客户端本地存档不可作为真实付费资产的权威来源。

## 操作

3D：WASD 移动，鼠标转向，R 鱼竿，按住左键蓄力/收线，松开抛竿/泄力；咬钩时点击提竿。右键收回空线，E 与 NPC/船只交互，I 鱼箱，J 航海日志，Esc 释放鼠标或关闭弹层。顶部“码头钓鱼”直接前往钓点。

触屏：屏幕按钮控制抛竿与收线；3D 版另有移动方向键及拖动转向。
